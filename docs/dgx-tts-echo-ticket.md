## 1. 复现步骤

```bash
KEY=<DGX_API_KEY>
URL=https://angineer.cn/api/tts2/v1/audio/speech

# 1) 抓一段流式 PCM（out.pcm 是裸 PCM：24kHz / 16bit / 单声道）
curl -s -N --max-time 40 -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" --data-binary @draft.json "$URL" > out.pcm

# 2) 包一层 WAV 头后送 ASR（或直接用你们的 ASR 工具）
curl -s -H "Authorization: Bearer $KEY" \
  -F "model=qwen3-asr" -F "language=auto" -F "file=@out.wav" \
  https://angineer.cn/api/asr/audio/transcriptions
```

- 复现时间：**2026-09-09 17:15–17:17（+08:00）**
- 输入文本见文末附录
